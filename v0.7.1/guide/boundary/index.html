Boundary conditions

This guide is a work in progress. For now, see the concept column Boundary conditions for the physics, and the boundary API reference for the exact signatures.

The picture

A boundary condition in LatticeCore is a composite object:

LatticeBoundary(
    axes     = (PeriodicAxis(), OpenAxis()),   # one AbstractAxisBC per axis
    modifier = NoModifier(),                   # non-topological reweighting
)

The axes decide which candidate bonds exist — they wrap, clamp, or attach a phase to a bond that would otherwise leave the sample. The modifier decides how existing bonds are weighted (e.g. sine-square deformation). Splitting the two concerns this way means a cylinder and an SSD modification can be composed without any core code change.

What LatticeCore ships today

  • Axis BCs: PeriodicAxis, OpenAxis, TwistedAxis.
  • Modifiers: NoModifier, SSD (type only; the weighting rule will land with the MC layer).
  • Hooks: apply_axis_bc, axis_phase, bond_weight.
