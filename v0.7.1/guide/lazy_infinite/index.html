Lazy / infinite lattices

This guide is a work in progress. See the concept column Quasiperiodic order for the physical motivation.

Size traits

LatticeCore describes the extent of a lattice through an AbstractSizeTrait value attached to every concrete lattice via size_trait:

  • FiniteSize — ordinary finite lattice. MC is safe.
  • InfiniteSize — conceptually infinite. MC is not safe; use the lattice only for spectral / analytic work.
  • QuasiInfiniteSize — conceptually infinite but expected to be materialised at a cutoff before use.

is_finite(lat) is a one-liner derived from this trait and is the predicate Monte Carlo algorithms should guard on.

The infinite-abstract → finite-materialisation pattern

LatticeCore ships two small hooks for this pattern:

  • materialize(abstract; kwargs...) — a generic function with no typed supertype. A package that defines an "infinite abstract" type (e.g. InfiniteFibonacci) adds a method for it that returns a FiniteSize concrete lattice.
  • require_finite(lat) — an assertion guard that MC entry points should call:
function run!(rng, state, lat::AbstractLattice, model, alg; kwargs...)
    require_finite(lat)
    # ... safe from here ...
end

This pattern mirrors the momentum-space counterpart: HyperReciprocalLattice is the "infinite abstract" that becomes a finite BraggPeakSet at a cutoff.
